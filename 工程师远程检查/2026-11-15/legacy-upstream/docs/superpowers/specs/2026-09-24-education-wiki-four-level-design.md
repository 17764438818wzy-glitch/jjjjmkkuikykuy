# 教育论文四级 Wiki 分类设计

> 初版分类说明：后续课例比较样本证明需要单列“课例与文本分析 → 课例比较”，核验层词表已增加这一入口。下文“六个入口”记录的是解析前草案，当前试跑应以核验层词表和生成导航为准。

## 目的与边界

本设计用于一条共用的教育论文研究范例 Pipeline。Wiki 帮使用者找到可追溯的写作范例；Graph 表达论文实际完成的研究路径；Tree / PageIndex 保留原文章节及其任务。Wiki 不生成独立于论文证据的百科结论。

本阶段只确定分类与构建规则，不修改代码、知识库或线上 Pipeline。财会链路的全文交接、一次标注、程序准入、正文切片和混合检索顺序保持为参照。教育类规则单独定义。

候选来源是桌面“`小学教育`”文件夹。只读盘点得到 2,592 个文件，其中 2,457 个扩展名为 `.doc`、`.docx` 或 `.pdf`。目录覆盖小学教育、教育学、学前教育、特殊教育、体育教育、音乐教育、汉语国际教育等；按学校归档的目录也含小学教育论文。文件名中含“现状”的文档有 499 个，含“策略”的有 329 个。文件数不是去重后的论文数，标题词不是研究方法的证据。另抽看了九个专业／学校目录的 DOCX 正文，用于发现分类边界，尚未对全量论文作质量判断。

## 核心决定

1. 整个文件夹进入候选池；单篇是否准入由正文中的教育研究问题与实际工作决定。来源专业保留为字段。体育、音乐、汉语国际教育等专业可共用这条 Pipeline；缺乏教育问题的运动消费、俱乐部经营等论文不进入教育范例 Wiki。
2. 四级 Wiki 采用“研究任务族 → 具体论文类型 → 实际研究路径 → 范例论文”。专业、学段、学科、研究对象和档位作为筛选字段，不占固定层级。
3. 第一、二级先定义受控分类；第三级经代表性样本校准后逐篇增量形成；第四级仅挂接通过准入并有来源证据的真实论文。没有范例的分类可以留在内部词表，不生成空的公开导航页。
4. 每篇论文有一个主挂接路径，可有带证据的次要交叉链接；Wiki 展示同一个稳定 `paper_id`，不复制论文实体。
5. 旧的“分级导航与论文写法范例”数据库模板不是本设计所指的现行 Wiki 模板，不作为部署依据。

## 四级结构

| 级别 | 稳定含义 | 初版候选分类或示例 | 创建规则 |
| --- | --- | --- | --- |
| L1 研究任务族 | 作者实际要完成的研究任务 | 调查诊断、设计与实践、干预评估、个案与叙事、文本与课程分析、理论与文献分析 | 解析前定义 ID 和边界；必要时保留内部“待归类”，不公开为空目录 |
| L2 具体论文类型 | 可供写作借鉴的论文形态 | 现状调查与对策、需求／问题分析、教学设计论证、教学设计与实施、行动研究、前后测干预研究、课堂观察、个案研究、教材内容分析等 | 从受控词表选择；不能只按题名选择 |
| L3 实际研究路径 | 正文证明已完成的步骤及顺序 | 问卷采集→描述分析→问题归纳→对策；设计→试教→观察→反思；前测→干预→后测→比较 | 从证据化步骤组合；同义路径归并，关键步骤不同则分开 |
| L4 范例论文 | 真实的、可追溯的论文 | `paper_id`、范例档位、适用条件、证据章节 | 仅在“入库”后挂接；带原文文档、章节、chunk 引用 |

L1 是浏览入口，L2 是论文类型，L3 回答“怎样做”，L4 提供可核查的实例。同一类型可有多条路径，例如“教学设计论证”止于设计，“教学设计与实施”包含课堂实施；后者不能从前者的标题或建议章节推断出来。

## 一级和二级初版词表

| L1 | L2 初版候选 | 判别重点 |
| --- | --- | --- |
| 调查诊断 | 现状调查与对策；需求／问题分析；多主体比较调查 | 有实际调查、访谈或观察材料及分析；对策是否由发现支撑 |
| 设计与实践 | 教学／活动设计论证；教学／活动设计与实施；行动研究 | 区分方案、试教或实施、循环改进三个不同完成程度 |
| 干预评估 | 单组前后测；有比较组的干预；实施效果的混合方法评估 | 核对实施、测量和分析；不因分数变化自动认定因果效果 |
| 个案与叙事 | 课堂观察研究；学生／教师／学校个案；教育叙事 | 有案例边界、记录材料、分析过程，不把案例描述当成干预 |
| 文本与课程分析 | 教材／绘本内容分析；课程或活动资源分析；政策／制度文本分析 | 有明确文本语料、分析维度和实际分析结果 |
| 理论与文献分析 | 教育思想／理论阐释；规范的文献综述 | 核对材料范围、梳理方法和原创分析；纯资料汇编不自动准入 |

这些名称是初版词表，代表性样本校准后再固定 `taxonomy_version=education-wiki/1.0`。来源专业和题目方向只作为候选信号。诸如“语文阅读教学”“家园共育”“特殊教育课堂”“体育课程”属于领域或场景筛选，不应生成同名的研究方法路径。

## 路径和挂接的证据规则

每个 L3 步骤应记录 `step_type`、实际／计划／不明状态、顺序、所用材料、分析要素、原文位置和简短引文。只有实际状态的步骤能构成公开 Wiki 路径和 Graph 边。计划与建议可保留在论文 Profile，不能冒充完成的研究。

| 材料或步骤 | 认定为实际执行所需的正文证据 |
| --- | --- |
| 问卷 | 调查对象、工具或题项、发放／回收或有效样本、结果分析；仅有“拟采用问卷法”不足 |
| 访谈 | 对象、提纲或主题、实际访谈记录／编码／分析；方法清单不足 |
| 课堂观察 | 观察对象与时段、记录工具或观察维度、记录及分析；课堂背景叙述不足 |
| 教学设计 | 明确的目标、活动、材料和设计说明可证明“完成设计”；实施另需课堂或活动记录 |
| 行动研究 | 实施轮次、各轮观察与反思、后续调整；题名中的“行动研究”不足 |
| 干预和前后测 | 前测、干预、后测、样本与指标及分析分别有证据；效果表述受研究设计约束 |

Graph 保留与财会链路兼容的 `paper_type`、`research_path`、`material`、`analysis_element`，教育类增加 `education_context` 和 `research_step`。班级、学校、年份等来源特征放在论文属性中，不扩成跨论文公共节点。每条关系带 `paper_id` 与章节／chunk 证据。Tree 保留原文章节顺序及其任务，不按 Wiki 路径重排原文。

## 标注与准入接口

一次完整论文标注至少产出：`source_major`、`education_context`（学段、学科、教育场景）、`research_object`、`paper_type`、实际步骤及状态、`materials`、`analysis_elements`、研究问题与发现、结论边界、质量裁决、`artifact_profile`、范例档位候选，以及对应原文证据。程序继续校验全文哈希、结尾覆盖标记、字段结构、引文定位和步骤／材料关系。技术失败独立于论文低质。

“入库”论文才建立 L4；“暂缓”保留问题与缺口，不出现在公开范例导航；“剔除”记录原因。图表和图片仍以辅助材料角色索引，不能单独充当正文已执行步骤的证据。

范例档位暂沿用函授、普通本科、重点本科三个候选档位，保持现有使用方式；教育类另设判据，关注问题范围、实际工作量、材料与分析完整性及结论边界。档位不等于学校审核结论，也不改变质量准入。新论文必须重新采集自身的问卷、访谈、观察、作品、前后测和实施结果，不迁移旧论文数据或结论。

## 构建顺序与版本管理

1. 固定 L1／L2 的初版 ID、定义和排除边界，同时确定专业、学段、学科等筛选字段。
2. 从各专业族选择覆盖不同任务类型的代表性论文试跑标注，人工审阅“设计／实施／效果”边界和路径同义词；九篇只读抽样不足以完成这一步。
3. 发布 `education-wiki/1.0` 词表。分类 ID 稳定，显示名称可改；新增同义词通过别名映射，不直接改历史 `paper_id` 或证据引用。
4. 随每篇入库论文增量更新 L3／L4。若证据不足，保留待核查状态，不以标题补齐路径。单篇 Graph 构建失败时不把不完整路径发布到 Wiki。
5. 全量解析后检查空目录、近义重复、主路径错挂、跨专业检索覆盖和每条范例的证据回链。分类版本变化时记录迁移映射，再决定是否重建导航或索引。

## 检索行为

“找范例”先查 Wiki 的任务族、论文类型、路径和档位；“怎么完成研究”先查 Graph 的实际步骤；“原文如何写”沿 Tree 返回对应章节和 chunk。全文与向量检索共同召回，并按专业、学段、学科、实际材料和档位筛选。回答最终落到真实 `paper_id`、章节和 chunk；Wiki 分类本身不替代论文证据。

## 审阅重点

首版保留 L1 六个入口；“理论与文献分析”仅在出现合格范例后展示。用户审阅时可调整入口名称或边界。后续代表性样本试跑仍可能调整 L2 名称与 L3 路径词表；本设计不声称已验证全量语料。
