# 一次模型请求的论文预提取实施记录

**Goal:** 保持现有 paper-preextract/1.0 MD 字段、完整学习内容和证据要求，程序前处理，一次模型请求，程序校验、脱敏、切片、封包、投递与读回。

**Architecture:** 依用户后续纠正，沿用 upstream 原工作台和 AutoProcessor 控制骨架，只替换单篇语义提取与 MD 后处理接点。原生解析、转换、定位、费用、并发、停止及结果页复用；Paperflow 精确计数、封包和直接切片读回复用。额外独立页签已撤回。

**Spec:** 用户本轮提供的七步完整方案、原工作台内修改的纠正、指定新模型接口，以及从“总论文”选择十篇试跑及核对历史指纹的后续授权；权威模板 E:/rag mid/exports/论文预提取_空白模板_v1.md。

**Execution:** 主 agent 实现材料、一次请求及入口；独立模块并行实现契约和发布；只读审查者复核实际结果。现有工作区大量未提交改动，新增独立模块，修改旧入口前保存备份，不回滚他人改动。

## 约束

- 一次模型 HTTP 请求，无自动语义补交、重试、降级或全文截断；失败保存原始输出和明确异常。
- 原稿、身份原值、私有路径与脱敏计划留私有目录；任何 filled_candidate 都不是已脱敏或已入库。
- 保留摘要、正文、公式、图表、参考文献、研究附录；不确定清理边界保留。
- 正文仅一份，图像字节实际进入模型请求；输入容量不足事前阻断。
- 程序事实有哈希、版本和定位；只处理确定格式错误，不规则补造研究事实。
- 全部学习字段进入可检索文本；各三级专业独立路由。
- 每篇材料归私有目录，沿原队列和批次保存；仅运行授权的十篇及随后追加的30篇，不恢复生产 Manager 或历史未决写入。
