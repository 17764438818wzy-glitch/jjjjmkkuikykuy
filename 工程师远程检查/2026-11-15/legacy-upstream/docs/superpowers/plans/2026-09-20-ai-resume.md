# AI phase resume implementation plan

> **For agentic workers:** Use superpowers:executing-plans to implement this approved design in the current session.

**Goal:** Retry failed AI work from page two without parsing source files or extracting native figures again.

**Architecture:** Save an immutable private preparation checkpoint immediately after native package creation. An explicit `retry_ai` operation restores that checkpoint into a new work directory and uses existing validated-response caches for unchanged AI calls. Preserve logical batch history through `retry_of`.

**Tech Stack:** Python 3.14, Tkinter, pytest, existing JSON manifests.

**Spec:** User-approved conversation and docs/script-task-page.md. Page one owns script work; page two owns AI failure diagnosis and retry.

## Global constraints

- Preserve parallel execution, upload admission checks and successful records.
- No live model requests or document uploads during validation.
- Source changes, missing/corrupt checkpoints and incompatible preparation versions must stop AI-only resume before paid work. Never fall back to native preparation.
- Current model settings apply on retry; request-keyed cache only reuses unchanged validated responses.
- Existing dirty workspace retained; no commit of unrelated changes or restart of active app.

## Review focus

- Parallel child records reference checkpoints within the main store, not the new worker store.
- Selected retries must not include passed or hidden/unselected papers; retry-all operates on full logical batch.
- Old results lacking checkpoints must provide actionable messages.
- A changed/deleted source must not silently reuse stale source contents.
- Repeated failure must retain its own checkpoint and logical batch history.
