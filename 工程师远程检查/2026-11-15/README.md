# Paperflow 工程师交接源码

这是 2026-11-15 从用户 Windows 处理电脑与局域网服务器整理的源码快照，供远程工程师检查项目。当前仓库公开，配置已制作成样例；不包含生产密码、API Key、SSH 私钥、真实论文原件、运行账本或数据库内容。

先读 [宿主机、服务器、NAS 详细说明](docs/01-宿主机-服务器-NAS-详细说明.md)，再读 [工程师远程检查指南](docs/02-工程师远程检查指南.md)、[代码证据索引](docs/03-代码证据索引.md) 和 [上传范围与验证](docs/04-上传范围与验证.md)。

| 目录 | 作用 |
| --- | --- |
| `paperflow/` | 当前 Paperflow V3、共享层、首步、前端、文章库及历史候选源码和测试 |
| `desktop-program/` | 实际跨目录依赖、当前选中 release、模板、部分 vendor 源码 |
| `legacy-original-core/` / `legacy-upstream/` | 当前路径配置引用的旧工程源码 |
| `workbench/` | 已定位工作台 release 的工程文件 |
| `server-live/` | 相关 Linux 部署目录中的可公开源码副本与部署文件 |
| `nimble-launchers/` | 本机模型的启动管理脚本；不含模型和运行时 |
| `evidence/` | 脱敏运行快照、依赖版本、文件来源与摘要、验证结果 |
| `tools/` | 本次交接的离线核验工具 |

当前主链入口是 `paperflow/candidates/parent-child-v3-20261102`。当前配置主后端为 8097/Qdrant，8088/RAGFlow 仍有旧任务兼容用途。Windows 执行论文处理，Linux 提供共享服务，NAS 保存原文与原始附件。

这是用于审查和隔离复现的源码交接，不是可直接在另一台电脑恢复生产的完整镜像。启动脚本和部分导入/维护入口有实际业务副作用；请先核对路径与隔离配置。源码导出清单不是生产发布清单；历史报告的“通过”也不代表本次全链已验收。
