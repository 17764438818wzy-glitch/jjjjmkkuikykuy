# 前端到等待 LLM 队列接线计划

范围：第一步任务控制、接收和前处理、等待 LLM 队列的可信计数。停止在等待 LLM，不连接或调用后续模型、RAG、NAS；不新增任务锁。

1. 用现有第一步健康状态说明实际进程、登记目录和分类索引；接收器只在同一实例、同一会话中完成稳定扫描后确认空队列。
2. 复用已登记的小工单和前处理交接记录，页面显示带时间的本地工单快照；Prefect 可用性另行核对，不宣称已逐条核对实时状态。扫描未完成时只显示已登记的正数，无法确认的零值显示未知；其他阶段继续显示未知。
3. 区分 Prefect 工作池不可用与尚无队列；开始、暂停的同步未确认时在页面保留提示，读取同一任务和控制版本确认后才清除。
4. 不运行真实或模拟业务任务、不调用模型；仅做语法、只读服务状态核对与独立静态复核。
