## 接收约定

- 上游任务接口中同时满足 `status=passed`、`delivery_complete=true`、`registration_status=registered` 的资料组才有资格接收；题目待核对本身不拦截。
- 根据 `paper_id`、`group_id`、`receipt_id`、回执路径和交付目录核对身份、正文及附件的文件编号、路径、大小、SHA-256 和相应证据。使用交付副本，不复制全部文件；垃圾不作为本地下游输入。
- 上游预留、本地核验并写入记录、上游确认均完成后，资料组才计入等待数。重复发现同一组不重复计数；身份冲突、文件失效或上游保护不能核实的组应待核，不作为正常等待组。
- 未来下游领取前必须重新完整校验。领取语义目前仅在合成环境验证；真实消费者尚未接入，领取写接口默认关闭。接通消费者时，必须再次验证幂等领取、中断恢复、上游引用和等待数递减。
