# 持久意图实验：禁止直接接线

`durable_gate.py` 只在一次性本地 MySQL 上验证文档写入/变更协调的基本思路，不是 RAGFlow 修改，也不是完整的生产协议。实验记录写入身份和摘要、未决状态、变更身份及版本；未知写入保持阻塞。

它尚未接入实际文档 API、后台线程、权限变更、Elasticsearch、原生计数事务和客户端查询／恢复；不能用来证明生产安全。未知状态解除和异常变更的恢复仍需设计与验证。实验库由 `tests/test_mysql_named_lock.py` 通过 `RAG_ISOLATED_MYSQL=1` 启动在本机环回地址并在测试后关闭，不使用项目数据库。
