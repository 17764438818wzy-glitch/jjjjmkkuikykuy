# 隔离候选，禁止接入或替换运行服务

此目录只用于本机测试，不是可部署补丁。它没有注册真实 RAGFlow 入口，字段和表没有在运行数据库中迁移，真实权限与文档、数据集变更的共同门禁尚未接入。单独启用新入口不能约束原有入口、后台执行器及其他服务进程。

`completed` 只表示该候选已收到匹配的 ES 写入应答，且 SQL 计数与终态在同一事务提交；它不表示全文读回、检索、整篇论文交付或 NAS 归档已完成。超时、进程中断和部分成功仍须独立核对，候选不会自动重发或自动解决所有未决状态。

当前只在一次性本地 MySQL、模拟模型和模拟的本机 ES HTTP 服务验证过；实际模型、向量维度、真实 ES、鉴权、原有前后台写路径和 NAS 均未联验。工作线程 2／4 是**每个进程**的实验上限，不是 Prefect 的全局 20 路额度。
