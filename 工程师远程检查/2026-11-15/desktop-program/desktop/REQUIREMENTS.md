# 全自动论文预处理需求基准

用户已确认：把原始论文处理成干净、完整、结构清楚、带初步专业分类的入库文本，交给 RAGFlow 建库。

- 原文件只读。复用既有脱敏、专业分类和明显非论文 / 不足 3000 有效字符的基础筛除规则；不作学术水平评级。
- 保留正文、段落顺序、公式、表格原始值及行列、单位、来源。删除身份信息和致谢，不能改写研究事实。
- 原生提取优先。图表识别、敏感区域定位同一次视觉调用完成；只有实际修改的脱敏内容才可能需要局部复查。取消逐篇两轮全文视觉扫描。
- 疑难判定针对保留正文中的具体对象；目录、已删除封面、普通内容容器及编号格式不触发全文回退。
- 对真正无法原生解析的局部内容定向识别；没有文本层的扫描页按页识别一次。无法可靠定位或识别时直接不通过，记录位置，不猜测补齐。
- 初步专业分类沿用原分类表，脚本先判断，不明确时由 AI 补充；题名经校验和脱敏。
- 全自动，无人工审批。最终仅 pass / reject，界面为通过 / 不通过。AI 认为不能满足要求即不通过；有限重试后的技术失败也不通过，reason_kind 区分基础筛除、证据/脱敏失败、技术失败、停止。
- 人工浏览为 通过或不通过 / 中文专业 / 题名.md。机器包保留 document.md、ingest.md、assets、metadata。失败保留说明和原件，私有未脱敏副本不进入正式浏览目录。
- 通过只表示预处理合格，不代表质量评级或保证 AI 无错误。metadata 记录实际使用的核验方式，不能无条件把所有问题改为已解决。
- 保留开始/停止、选择、进度、费用统计、RAGFlow 连接/交接；预处理结果与交接状态分开记录，不能重复上传两种导出。
- 使用历史 37 页案例实测，不自动向 RAGFlow 上传测试文件。验证数值、正文保留、图片链接、分类、失败分类和调用/耗时，报告真实限制。
