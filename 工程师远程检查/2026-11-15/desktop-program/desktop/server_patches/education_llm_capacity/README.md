# 教育模型调用与执行容量

只匹配教育 md 库、现有学校/官方 Pipeline、EducationAnnotation 节点及各自模型 ID。

- 学校 OpenAI compatible：SDK 与 RAGFlow 均不内部重试，单次最多 180 秒。
- 官方 DeepSeek LiteLLM：`num_retries=0`、RAGFlow 不内部重试，单次最多 300 秒。
- HTTP/连接/超时故障从真实 SDK 异常生成有限字段标记，不包含供应商响应正文；论文和模型生成字符串不能作为故障来源。
- 本地诊断再次核对库、Pipeline、模型、本轮执行与全文后，交给持久队列处理暂停和有限切换。
- 固定路由配额为学校 2、官方 4，总量 6；不借用学校空闲席位。认证/欠费保留通道停止状态。
- 服务器文档执行名额为基础执行器 1 加补充执行器 5，教育各通道名额由持久队列分别约束。

`install.py` 使用部署源码 SHA、原文件备份和幂等校验；部署前排空解析，重载执行器。
`probe.py` 在服务器使用真实 RAGFlow Base、OpenAI SDK 和 LiteLLMBase 做离线故障注入，无外部模型请求。

私有路由配置、服务器启动脚本和接管回执位于私有目录及服务器挂载日志目录，不在此保存连接凭据。
