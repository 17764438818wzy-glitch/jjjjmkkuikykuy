## API 地址缺少版本路径的报错修复

实测原配置根域名返回 HTTP 200 text/html；同域名 /v1/models 返回模型列表，所选模型存在。补全路径后文字探测、随机色块视觉探测均通过。程序对仅域名的地址补 /v1，自定义路径保持不变；HTML 返回不再重试，截断与结构字段错误保留具体原因。相关26项测试通过。


## Agent 模型配置界面整理

将专业绑定、自动导入及自动解析选项移至 RAGFlow 连接页。Agent 模型页仅配置文字判断、图表识别模型与运行参数；顶部固定读取模型、模型连通测试和保存按钮，窄窗口/大进度面板时仍可操作。模型下拉列表可手动输入；按当前选择的服务分别读取模型及测试。图表测试核对随机四色图，不能仅凭“收到”就声称能读取图片。模型配置修改后测试状态失效，运行中的测试返回时也检查配置是否变化。
