# 预处理并发加速实施计划

> 先用失败测试锁定配置、闸门、断点状态和失败隔离，再实现；默认关闭并发，未完成中转站探测前不擅自提高生产默认值。

## 范围

- 只改本地预处理工具；不改 RAGFlow 链路、双库分流、上传去重、图片投影、会计学标注和知识包结构。
- 增加文档级并发、单篇图片级并发、跨文档全局 LLM 闸门。
- 每张图片完成后立即写入线程安全的处理状态；保留现有 stage cache 作为重跑时的模型结果复用机制。
- 429、5xx、超时走现有 Agent 重试并增加可配置退避；不可重试错误不重复浪费请求。
- 默认 `concurrency.enabled = false`，直到真实中转站探测完成；开启后保守默认 2/2/4。

## 交付顺序

1. 添加独立并发探测脚本和结果记录格式；无可用生产凭据时明确不做虚假实测。
2. 添加配置兼容、UI 参数和断点状态存储。
3. 在 Agent 网络请求层接入全局信号量，并在图片识别层实现图片级线程池。
4. 将单篇预处理调度为文档级线程池，主线程串行提交 manifest 进度和结果。
5. 添加失败隔离、失败清单、ETA/并发观测日志和 `--limit` 入口。
6. 运行活动测试并做可控的本地并发、停止/续跑验证。
