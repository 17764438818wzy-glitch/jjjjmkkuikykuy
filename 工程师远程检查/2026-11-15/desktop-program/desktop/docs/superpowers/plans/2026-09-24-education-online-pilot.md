# 教育研究范例链路线上试跑计划

目标：在隔离的教育试验库与新 Pipeline 上验证八篇已通过预处理的论文，保留财会库和财会 Pipeline 原状。

1. 冻结八个来源知识包的试跑副本；验证清单、稳定论文编号、全文与隐私状态。记录其中的教育范围边界样本，不能预判其入库。
2. 从财会 Pipeline 的可运行拓扑复制骨架，单独编写教育领域的交接校验、完整标注、准入与索引字段。用本地单元测试验证稳定 ID、教育准入、实际研究步骤和来源引文；不复用财会专业词表。
3. 新建教育 PageIndex／Graph 模板组与 Wiki 模板组。Graph 提取具体论文类型、教育场景、实际步骤、材料与分析要素；Wiki 按研究任务族、具体类型、路径、论文四级导航；均要求原文来源。
4. 新建教育 Pipeline、md 试验知识库与图片试验知识库，绑定现有可用模型与 `text-embedding-v4`。核对线上配置只引用新建教育对象，之后才上传试跑副本。
5. 先解析一篇完整的调查论文，核对身份、标注、准入、Tree、Graph、Wiki 和索引。通过后再提交其余七篇；记录逐篇结果、时间、失败阶段和可回链来源。技术失败与学术质量裁决分开。

任何阻断校验失败时停在该阶段，记录证据并修复后续步骤；不得以成功上传代替解析成功。
