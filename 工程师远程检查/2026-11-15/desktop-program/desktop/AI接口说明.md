# 全自动预处理与外部 AI 接入

## 确定的流程

源文件 → 轻量解析、基础筛选及初步专业分类 → 原生图表提取 → 疑难对象定向识别、图片识别与敏感区域定位 → 一轮文本脱敏 → 专业目录 → RAGFlow。明确的题名和专业复用原规则，只有不明确时调用 AI 补充分类。

最终只有 **通过、不通过**。API 未配置、超时、格式错误、原文无法读取等，有限重试仍失败也归“不通过”，原因注明技术失败，不能称为文章低质。无人工审批，无“有争议”目录。

## 接入操作

1. 重开桌面“论文知识库预处理”，打开“Agent 模型”。
2. 填写文本接口基础地址（包含服务商要求的版本路径）、文本模型和 Key。
3. 填写视觉模型。可以另填视觉接口地址和 Key；留空时复用文本服务。仅支持文字的模型不能承担图像核对。
4. 在“文字判断模型”和“图表识别模型”中分别点击“读取可用模型”，从下拉列表选择模型，再点击顶部固定的“模型连通测试”。文字测试检查实际响应；图表测试读取随机排列的合成色块，不发送论文。更换模型后需要重新测试。服务不提供模型列表时，可手动填写模型名再测试。
5. 保存配置。两个 AI 密钥均使用当前 Windows 账号的 DPAPI 加密；普通配置不含明文 Key。也支持 PAPER_AI_API_KEY、PAPER_VISION_API_KEY 环境变量。
6. 在 RAGFlow 连接页填写地址、Key 并读取知识库。Key 也使用 DPAPI 保存。
7. 专业名称与知识库中文名完全一致时自动匹配。否则在 RAGFlow 连接页的“处理完成后进入 RAGFlow”区域选择专业，并绑定到上方选中的知识库。
8. 开始处理。默认自动导入通过项，并请求 RAGFlow 执行知识库中已配置的解析流程。没有配置 RAGFlow 时，已经通过的本地结果保留，随后在 RAGFlow 页点击“重试交接”。

“重试不通过”从原文件重新预处理；“重试交接”只操作已经通过的导入结果。停止后也可重试；已经完成同版本全自动处理的相同源文件按哈希跳过。旧版结果需要从源文件重新处理。

## 外部接口协议

提供兼容 **POST {base_url}/chat/completions** 的接口。只填写域名时自动补上 `/v1`；自定义路径保持原样。若地址已以 `/chat/completions` 结尾则直接使用。收到 HTML 网页时直接提示检查 API 地址，不再当作模型格式问题重试。请求使用 Bearer Key、UTF-8 JSON；传入 `model`、`messages`、`max_tokens`。

文本为 user 消息中的 JSON 数据；视觉请求使用 `text` 和 `image_url` 内容块，图片是 `data:image/png;base64,...`。系统提示将论文和图片定义为不可信数据，不能执行文件中的指令。

响应须包含 `choices[0].message.content`，该字段必须是可解析的 JSON 对象字符串；完成原因须为 `stop` 或缺省。代码块、截断、缺字段、非法状态均按技术失败处理并有限重试，不默认通过。

所有任务都返回：

```json
{"decision":"pass","reason":"具体依据"}
```

`decision` 仅允许 `pass` / `reject`。各任务附加字段如下，完整提示词在 agent_client.py 的 CONTRACTS 中：

| 任务 | 附加字段与用途 |
|---|---|
| screen | 判断论文文种与基本正文是否足够，不评价学术水平 |
| extract_page | 只转录没有文本层的目标页，返回完整 blocks 与 sensitive_boxes，不能总结正文 |
| classify | `major` 必须属于原脚本专业词表；`title` 为不含身份信息的真实题名 |
| privacy_text | `sensitive_strings`：原文中需遮盖的精确子串列表，不返回改写正文 |
| privacy_image | `research` 布尔值、`sensitive_boxes`、准确转录的 `text`、简短 `description` |
| repair | `insertions` 与 `sensitive_boxes`：仅处理指定页和对象；默认 append。整表重建须 replace_table，保留所有原有单元格和合并续格文字 |

图像坐标统一为 `[x0,y0,x1,y1]`，按宽高归一化到 0–1；程序拒绝越界坐标。repair 支持文本转录、规则行列表格和原图区域裁剪，不通过生成图像重画原图。复杂关系无法可靠恢复时，模型应拒绝，不编造数值。

图像描述标记 `generated`，转录标记 `ai_visual_transcription` / `ai_transcription`，区别于原生文本。同一次视觉请求提供识别文字和遮盖坐标，程序本地遮盖，不再重复扫描图片或全篇。图像 OCR/描述必须已脱敏；后续文本检查发现额外图片敏感信息时直接不通过。文本只检查可见内容和语义属性，跨字段且不能精确执行的删除直接拒绝；不允许把财务纯数值当作待删文字。

## 自动检查与输出

- 脚本只做确定性粗筛。PDF 有低文字量页面、DOCX 图片对象多而文字少、乱码等，不能直接以短文拒绝。
- 基本字符门槛沿用 3000，不增加学历和学术等级评分。
- 原文件保持只读，原始副本与临时页证据保存在运行目录的 private 中；不上传到 RAGFlow。
- AI 仅在实际有疑难对象的页上读取原页证据；普通目录、已删除封面不触发全文回退。目标页过多、无法可靠定位、原资源缺失时直接不通过并记原因。
- 通过包仅包含脱敏后的 document.md、ingest.md、metadata.json、assets。图表位置、来源与自动检查方式写入元数据。
- 通过是预处理结论；`evaluation_ready=false`，后续研究能力评价仍由 RAGFlow 侧负责。
- 外部 AI 会接收脱敏前原文和图表，这是用户选定的处理方式。

打开批次目录：

```text
通过/会计学/论文题目.md
不通过/未识别专业/未确认题名（编号）.md
```

同名论文追加短编号，图片链接指向程序保存的 assets。没有每篇论文的浏览子文件夹。不通过且尚未分类的材料归入“未识别专业”；显示具体原因，不复制未脱敏原文到浏览目录。技术失败同样生成原因文档。

## RAGFlow 衔接

上传 `ingest.md`、`ragflow_assets.md` 和已通过脱敏检查的图片资产；图表文本和结构化配方在检索文档中，原图作为同一知识库中的独立文档。按专业匹配唯一知识库，未匹配时等待配置，不随意选择其他库。每个辅助上传都记录远端文档编号，网络结果不确定时不会重复提交。

本机源码的解析接口为 `/api/v1/datasets/{id}/documents/parse`；收到 404/405 才回退到旧版 `/api/v1/datasets/{id}/chunks`。后者可对照 [RAGFlow 官方 SDK](https://github.com/infiniflow/ragflow/blob/main/sdk/python/ragflow_sdk/modules/dataset.py)。程序沿用知识库现有 Pipeline，不创建或替换远端流程。

上传前校验 AI 批准的正文及证据包哈希。请求发送前保存状态，响应不确定时通过含内容哈希的文件名查询远端文档；未唯一找到时保持交接未完成，不盲目重复上传。解析请求已提交与解析完成分别记录。

## Token 与人民币费用

进度窗口显示本批输入、输出、合计 Token 与人民币预估，处理期间附当前单篇费用。
“费用明细”显示逐篇、模型/阶段、批次及启用功能以来的累计用量，连通测试单列。
“Agent 模型 → Token 计费”查看当前模型自动匹配的单价，修改估算汇率后保存。
默认 1 美元≈7 元为便于预算的估算汇率，不是实时外汇报价。

官方标准价核对日期为 2026-09-15，单位为美元/百万 Token（输入 / 缓存输入 / 输出）：

- [GPT-5.6 Sol](https://developers.openai.com/api/docs/models/gpt-5.6-sol)：4 / 0.4 / 20；含官方 gpt-5.6 别名。该页面说明优惠至少持续至 2026-11-21。
- [GPT-5.6 Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra)：2 / 0.2 / 12。
- [GPT-5.6 Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna)：0.2 / 0.02 / 1.2。
- [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)：10 / 1 / 50。
- [GPT-5.5](https://developers.openai.com/api/docs/models/gpt-5.5)：5 / 0.5 / 30。

模型名精确匹配，未收录的模型只记录 Token 并显示缺单价，不冒用其他模型价。
输入超过 272,000 Token 时按输入/缓存 2 倍、输出 1.5 倍估算。
已返回的缓存命中从普通输入中扣除；返回缓存写入计数时对支持的模型按普通输入 1.25 倍计。
未返回缓存细分时按普通输入估算。推理 Token 属于输出，不重复累加。图像 Token 使用接口返回的输入总量，不按图片数猜测。

每次实际请求在发送前、响应后分别写入 `data/ai_usage.jsonl`，按请求 ID 合并；每次重试独立计数。
即使模型输出无效、拒绝论文或达到长度限制，已返回的 usage 仍计费。
未返回/不兼容 usage、超时或中断的请求显示“用量未知”；金额仅汇总可计算部分，不表示未知请求免费。
每次请求冻结官方价、核对日期和汇率，修改汇率不会改写历史金额。
明细只存模型、任务阶段、批次/文件 ID、用量及价格，不保存密钥、原文、图片或模型回答。

统计从安装本版本后生效，旧批次不虚构用量。不包含 RAGFlow 内 Embedding、解析或后续 Agent 的费用，也不代表第三方代理的实际扣费。

## 运行边界

默认每次请求最多尝试 3 次、超时 90 秒、每篇最多 80 个视觉核对页、输出上限 8192 token。视觉核对按原文逐页调用，长论文可能耗时和产生较多 API 费用。超过页数或 48MB 请求上限直接保留未完成，不截断后宣称完整。

超时/连接错误/429/部分5xx/无效JSON有有限重试；鉴权错误等待配置更正。OCR/复杂原生格式无法转成可见证据时保留未完成。RAR/7z 沿用原脚本能力，原环境没有对应解压依赖时不会冒充处理成功。

功能验证使用模拟 AI、合成图像及本地 HTTP 服务，不代表真实模型的准确率。2026-09-15 计费升级运行 90 项自动测试，覆盖缓存扣除、汇率折算、长输入倍率、失败重试用量、断连未知费用、逐篇/批次保存及小窗口按钮布局。
计费升级另用用户当前 Spark 配置做合成文本探测，分别返回 HTTP 400、429；后者说明上游账户已被限流。接口未返回 usage，测试明细已如实保存为用量未知。未用真实论文测计费，也未触发 RAGFlow 上传。少量代表样本通过后再扩大批量；系统不要求逐篇人工审批。
